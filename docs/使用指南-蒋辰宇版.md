## 一、这个项目是干什么的？

**一句话**：你在 BOSS 直聘上看到岗位 → 发给 Hermes → 系统自动判断"值不值得投" + 生成一份"诚实定制版简历" → 你审核后自己投。

**完整流程**：
```
你看到岗位（截图/链接/文字）
   ↓ ① 发给 Hermes，说"录入岗位跑一下"
   ↓ ② 系统评分（薪资/地点/学历是否达标）
   ↓ ③ JD 匹配率分析（你有多合适）
   ↓ ④ 生成定制简历（自动避坑：不冒充头衔、不编造数字）
   ↓ ⑤ 诚实护栏检查 + T2 终检
   ↓ ⑥ 自动出 PDF（在 桌面/Atlas 文件夹）
   ↓ ⑦ 你打开 PDF 看，满意就投，不满意让 Hermes 改
```

## 四、岗位怎么加？（重点）

岗位存在 `data/jobs/validation/` 文件夹里，每个岗位一个 JSON 文件。

### 最省事方式：让 Hermes 帮你加
截图发 Hermes，说"录入岗位"，它会自动创建 JSON + 跑流程。**推荐这个**。

### 手动方式（了解结构）
在 `data/jobs/validation/` 建个 `boss-XX.json`：
```json
{
  "id": "boss-08",
  "title": "岗位名称",
  "company": "公司名",
  "industry": "行业",
  "salary_text": "6-9K",
  "location": "丽水",
  "remote": false,
  "employment_type": "全职",
  "work_schedule": "",
  "job_description": "岗位职责：...任职要求：...",
  "tags": [],
  "honest_constraints": [
    "角色头衔必须为事实清单原文（市场人员/项目成员/政企客户经理），禁止写成XXX",
    "禁止声称XXX，可写XXX"
  ]
}
```
然后跑 `node --experimental-strip-types scripts/e2e-one.ts boss-08`

### 💡 honest_constraints 怎么写（重点！）
这是"诚实约束"——告诉 AI 哪些话不能说。你的**身份底线**是：
- 头衔只能是：**市场人员 / 项目成员 / 政企客户经理**（不能冒充项目经理/主管/顾问）
- 没做过的事不能说"精通/主导/负责管理"
- 但可以写"参与/跟进/推动/协调"

## 五、怎么读结果？（看这 5 行就够）

```
[评分] 3.3 | pass          ← 达标可投（fail=薪资/地点被拒，不用看后面）
[JD分析] 匹配率 25%          ← 越高越合适（70%+ 很好，30% 以下谨慎）
[护栏] 判定: PASS           ← PASS/REVIEW 可继续；REJECT=有造假被拦（好事）
[终检] FIX                 ← PASS 最好；FIX 微调；REWRITE 大改（说明夸大或跑偏）
[投递包] ✅                 ← 简历 txt+PDF 已生成
```

### 判定速查表
| 看到 | 意思 | 怎么办 |
|------|------|--------|
| 评分 fail | 薪资/地点/学历不过底线 | 放弃，别投 |
| 匹配率 <30% | 你经历和岗位差太远 | 一般不建议投 |
| 护栏 REJECT | AI 编了假数字/假头衔 | 系统保护你，重跑或换岗位 |
| 终检 REWRITE | 简历有夸大 | 让 Hermes 加诚实约束重跑 |
| 终检 FIX | 基本 OK，小调整 | 可以直接用 |

## 六、源简历在哪改？（重要！）

**所有简历的"事实源头"**：`data/source_resume.json`

- 你换工作/加经历，改这个文件
- 系统只从这里取事实，**绝不会编造文件之外的内容**
- 改了之后所有岗位的简历都会自动用新内容

⚠️ **不要手滑改错**——这是"真相源"，数字错了全盘皆错。改完可以跑 `npm test` 验证。

## 七、常见问题（FAQ）

**Q1：PDF 在哪？**
`桌面\Atlas\` 下，文件名带岗位号，如 `定制简历_boss-06_蒋辰宇.pdf`。

**Q2：跑的时候报"找不到岗位"？**
ID 写错了。先看 `data/jobs/validation/` 里有哪些文件，用文件名（去掉 .json）当 ID。

**Q3：跑一次要多久？**
单岗位约 1-2 分钟（LLM 调用 + 15 秒间隔）；全量 7 岗位约 3-4 分钟。

**Q4：想换主模型（比如用 qwen 试试）？**
改 `lib/llm.ts` 里的 `MODELS`（T1=起草，T2=审查）。TokenRhythm 有 16 个模型可选。

**Q5：临时放宽地点怎么用？**
```bash
LOCATIONS=丽水,杭州 node --experimental-strip-types scripts/e2e-one.ts boss-07
```
（Windows 终端直接加在命令前）

**Q6：AI 编了假数字怎么办？**
不会漏——有"数字白名单"（只能引用源简历里的数字）+ 诚实护栏双重拦截。真编了会被 REJECT，重跑一次通常就好（LLM 有随机性）。

**Q7：为什么有时候"REWRITE"？**
说明 AI 觉得简历有夸大/跑偏。让它加诚实约束重跑，或换更匹配的岗位。**REWRITE 是保护不是失败**。

**Q8：我的底线配置在哪改？**
`scripts/e2e-one.ts` 里：
- 最低薪资：`min_net_salary = 5000`（到手 5 千）
- 期望薪资：`target_net_salary = 6000`
- 接受地点：`LOCATIONS` 环境变量（默认丽水）

## 九、一句话总结

> **你只做两件事：① 发岗位给 Hermes ② 审核 PDF 决定投不投。**
> 其余（评分、匹配、起草、防造假、排版）全是系统自动的。

遇到任何看不懂的输出，直接问 Hermes："这是什么意思？"——它会用大白话解释。
