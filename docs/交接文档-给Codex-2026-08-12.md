## 一、项目是什么

**BOSS 直聘半自动求职系统**，服务老板（蒋辰宇，求职者）：

```
搜岗位 → 评分排序 → 选岗 → 生成诚实定制简历(PDF) → 老板审核 → 手动投递
```

**核心原则（不可违反）**：
1. **诚实红线**：简历绝不虚构——头衔必须与源简历一致，数字只能原样引用白名单
2. **半自动**：所有投递前必须老板人工审核（pending → approved）
3. **薪资底线**：到手 5000/月（税前×0.86），地点：丽水（可环境变量放宽）

## 四、关键机制（踩坑总结，务必理解）

### 1. LLM 三端点（lib/llm.ts）
```
① TokenRhythm（tokenrhythm.studio/v1）— 主，deepseek-v4-flash-0731(起草)/pro(审查)
② opencode-go（opencode.ai/zen/go/v1）— 兜底1，⚠️必须带浏览器 User-Agent（否则 403/1010）
③ DeepSeek 直连（api.deepseek.com/v1）— 兜底2
```
- ⚠️ opencode.ai 有 Cloudflare 拦截，**无浏览器 UA 的请求一律 403**（曾被误判为"订阅过期"）
- ⚠️ luna 模型（gpt-5.6-luna）需要走代理 7890 才通，直连 403
- 免费档 zen/v1 已 CreditsError（余额不足），不要依赖

### 2. 诚实护栏体系（三道防线）
```
① draft prompt 铁律：头衔不得升格 + 数字白名单（只能原样引用）+ 身份诚实第8条
② guardrail 硬校验：每个数字必须能在 source 找到（数值比较，±1容差）
③ T2 终检：识别夸大/匹配不足（REWRITE/FIX）
```
- 数字白名单在 `buildFactSheet()`：列出所有可引用数字，白名单外数字=编造
- 已知坑：LLM 会尝试把 245.8+7.9+20 相加成"900万"——白名单+护栏双保险拦截

### 3. 岗位级诚实约束（job JSON 的 honest_constraints 字段）
每个岗位可配置专属约束（如 boss-06 禁止写成"项目经理"）。draft 会把这些约束注入 prompt。

### 4. BOSS 采集（cookies 直连，绕开反爬）
- 原理：BOSS 浏览器自动化会被检测（headless/headed 均白屏），但 **HTTP API + 登录 cookies** 可行
- 接口：`wapi/zpgeek/search/joblist.json?query=X&city=101210800&page=1&pageSize=N`
- cookies 有效期**极短**（几小时），code:37 = 过期，需老板重新导出（采集器有友好提示）
- 城市码：丽水 101210800 / 杭州 101210100
- ⚠️ 老板的 Chrome 有反调试（F12 白屏），导出 cookies 需用 Edge 或先开 F12 再访问

### 5. 评分规则（score.ts）
```
权重：主体15% 行业10% 岗位10% 财务10% 薪资25% 结构10% 通勤12% 模式8%
+ ⑨技能匹配加分（命中≥4类+0.5，3类+0.3，2类+0.1）
合法性：L2/L3/L5/L8 硬滤fail ｜ L6 低薪fail ｜ L7 外包review ｜ L1 面议标记 ｜ L4 地点前置
```
- 优势领域关键词：通信/信息化/教育/AI/招投标/客户市场/方案协调
- 时薪折算：×22天×8时（区间过大封顶 1.5×中位数）；日薪 ×22天
- 噪音过滤：医疗/施工/授课类岗位 L5 过滤（老板方向=市场/销售/项目/教育信息化）
